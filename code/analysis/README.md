# Analysis

Econometric estimation scripts for reproducing the paper's WTP estimates and
slope compression statistics.

## Scripts

| File | Description |
|------|-------------|
| `install_packages.R` | Install required R packages |
| `study1_estimation.R` | Study 1 logit estimation and WTP recovery |
| `study2_estimation.R` | Study 2 conditional logit estimation |
| `krinsky_robb.R` | Krinsky-Robb confidence intervals for WTP |

Scripts to be added by the team.

## Output

Results tables are written to `results/tables/`:
- `tableF13_wtp_s1.csv` — Study 1 WTP estimates
- `tableF14_slopes_s1.csv` — Study 1 slope compression
- `tableF19_wtp_s2.csv` — Study 2 WTP estimates
- `tableF20_slopes_s2.csv` — Study 2 slope compression
