# Data

## Overview

This directory contains two categories of data:

1. **Synthetic response data** (`data/synthetic/`) — generated by this study; freely available under CC BY 4.0
2. **Original human-survey data** (`data/raw/`) — *not redistributed* in this archive; see below

---

## Synthetic Response Data (`data/synthetic/`)

Synthetic responses are organized by study:

```
data/synthetic/
├── study1_nces/    # Aldy, Kotchen & Leiserowitz (2012) — NCES clean energy
└── study2_hwa/     # Giguere, Moore & Whitehead (2020) — HWA hemlock forest
```

### Schema

Each synthetic response panel is a CSV/parquet file with the following columns:

| Column | Type | Description |
|--------|------|-------------|
| `respondent_id` | string | Links to original survey respondent (anonymized) |
| `model` | string | LLM identifier (e.g., `gpt-5-mini`, `deepseek-chat-v3.1`) |
| `condition` | string | `demographics_only` \| `all_beliefs` \| `belief_{item_name}` |
| `bid` | float | Assigned bid amount ($/household/year) |
| `vote` | int | 1 = support, 0 = oppose |
| `confidence` | int | Self-reported confidence (1–5) |
| `rationale` | string | Free-text rationale from LLM |
| `run_id` | string | Unique Alethic-ISM run identifier |
| `timestamp` | datetime | API call timestamp |

### Replication

To regenerate synthetic data from scratch, see `code/simulation/README.md`.

## Original Human-Survey Data (`data/raw/`)

The original human-survey microdata are **not redistributed** in this archive due to
data-use agreements with the original study authors.

### Study 1: Aldy, Kotchen & Leiserowitz (2012)

> Aldy, J.E., Kotchen, M.J., & Leiserowitz, A.A. (2012). Willingness to Pay and
> Political Support for a US National Clean Energy Standard. *Nature Climate Change*, 2(8), 596–599.

Contact the authors to request individual-level data used for constructing synthetic personas.

### Study 2: Giguere, Moore & Whitehead (2020)

> Giguere, E., Moore, R., & Whitehead, J.C. (2020). Willingness to Pay for Hemlock
> Woolly Adelgid Control in North Carolina Public Forests. *Forest Policy and Economics*.

Contact the authors to request data. The dataset may also be available through
the Environmental Valuation Reference Inventory (EVRI) or upon direct request to
john.whitehead@appstate.edu.
